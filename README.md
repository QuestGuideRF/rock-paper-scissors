# Камень, ножницы, бумага

Консольная игра на Python. Игрок выбирает один из трёх вариантов, компьютер делает случайный ход, после чего программа определяет исход раунда.

## Запуск

```bash
python rock_paper_scissors.py
```

Введите «камень», «ножницы» или «бумага». Поддерживаются также варианты `rock`, `scissors` и `paper`. Сторонние библиотеки не требуются.
